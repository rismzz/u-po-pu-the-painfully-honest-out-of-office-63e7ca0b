A brutally honest but still polite out-of-office auto-reply, in exactly one sentence. It tells the truth — the inbox is being deliberately ignored while on leave to recharge — without getting anyone fired: anything genuinely urgent still gets answered on return.

## Run

```bash
python3 main.py
```

Writes the single sentence to `entry.txt` in the output directory (`/output` by default, or `$MAKEFUN_OUTPUT_DIR`). Deterministic, stdlib only, no network, no randomness — identical output on every run.
